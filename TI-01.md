# Administrador de estudiantes

## Objetivo

Construir una pequeña aplicación web que permita registrar estudiantes y mostrar su información dinámicamente utilizando Programación Orientada a Objetos (POO).

---

# Requerimientos

## HTML

Crea una interfaz que contenga:

* Un input para nombre del estudiante.
* Un input para edad.
* Un botón con el texto:
  `"Agregar estudiante"`.
* Un contenedor donde se mostrará la lista de estudiantes registrados.

---

## CSS

Aplica estilos básicos para:

* Mostrar cada estudiante en una tarjeta o contenedor.
* Separar visualmente los elementos.
* Mejorar la apariencia del formulario.
* Puedes utilizar Bootstrap 5 si lo deseas.

---

## JavaScript

Implementa lo siguiente:

1. Crear una clase llamada `Estudiante`.

2. La clase debe contener:

   * `id`
   * `nombre`
   * `edad`

3. Al hacer clic en `"Agregar estudiante"`:

   * Crear una nueva instancia de `Estudiante`.
   * Guardarla dentro de un arreglo.
   * Mostrar dinámicamente todos los estudiantes en pantalla.

4. Validar que:

   * Ningún campo esté vacío.
   * La edad sea numérica.

---

# Restricciones

* No utilizar jQuery.
* No utilizar frameworks.
* No utilizar APIs externas.
* Todo debe resolverse con JavaScript puro.

---

# Conceptos evaluados

* Programación Orientada a Objetos.
* Clases y objetos.
* Arreglos.
* Eventos.
* DOM.
* Validaciones.
* Funciones.
* `push`.
* `forEach`.

```
Nombre: Ana

```

```

```
